Taamey Frank CLM is the default reader font: it carries OpenType `GPOS` `mark` / `mkmk` tables for
the Hebrew script, so vowel points (ניקוד) and cantillation (טעמי המקרא) are anchored to their base
letters and stacked on each other instead of overlapping.
